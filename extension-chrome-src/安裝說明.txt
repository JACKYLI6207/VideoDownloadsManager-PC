Video Downloads Manager - Chrome 手動安裝（3 步）

【圖二按哪個？】
  點左邊那顆：「載入未封裝項目」
  （不要點「封裝擴充功能」）

【資料夾選哪個？】
  選本專案根目錄下的 extension-chrome-src 資料夾（不要選裡面的子資料夾）
  ※ 資料夾內不可有 _backups 等底線開頭目錄（Chrome 會拒絕載入；.git 沒問題）
  ※ 備份請用 scripts\backup.ps1（Git commit，歷史用 git log 查看）

【步驟】
  1. 網址列輸入 chrome://extensions/  Enter
  2. 右上角「開發人員模式」打開
  3. 點「載入未封裝項目」
  4. 選上面的 extension-chrome-src 資料夾
  5. 成功後列表會出現「Video Downloads Manager」

【若顯示錯誤 / 點圖示沒反應】
  1. 在擴充卡片上點重新整理圖示（圓形箭頭）
  2. 或移除後重新「載入未封裝項目」
  3. v1.0.8：設定頁可調「最大連線數」1～12（與 EXE 相同），HLS 片段改背景並行下載
  4. 已修復 v1.0.4：M3U8 403 修復（帶 Cookie/Referer、分頁內備援下載）
  5. v1.0.3：移除內部動畫、失敗任務保留顯示、新增「日誌」分頁

【使用】
  播放影片 → 點工具列擴充圖示 → 側邊欄選影片下載
